# ✈️ AeroTech — Interactive Aviation Encyclopedia & Web Application

AeroTech is a modern, responsive web application designed for aviation enthusiasts and researchers. It provides a structured interactive database of commercial and military aircraft, complete with real-time filtering, dynamic routing, and a full administrative dashboard powered by Firebase Firestore.

---

## ✨ Key Features

- 🔍 **Interactive Aircraft Catalog:** Browse military fighters and commercial jets with dynamic search and instant category filtering.
- ⚙️ **Admin Dashboard:** Secure administrative panel to add, update, and manage aircraft entries, manufacturers, and airline data in real time.
- 📱 **Fully Responsive UI:** Optimized layout across mobile, tablet, and desktop screens with a dark modern tech design.
- ⚡ **Firebase Firestore Integration:** Real-time database synchronization for seamless dynamic content management.

---

## 🛠️ Tech Stack & Tools

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend / Database:** Firebase Firestore
- **Deployment:** Netlify
- **Version Control:** Git & GitHub
